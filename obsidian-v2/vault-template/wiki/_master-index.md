# Wiki de conhecimento

Consolide aqui os aprendizados que continuarão úteis após uma entrega. Use nomes de arquivo curtos, sem prefixo de data, e mantenha a seção `## Key Takeaways`. Crie pastas por tema com um `_index.md` à medida que o conteúdo crescer.

Após entregar um projeto, use `/harvest <arquivo-do-projeto>` para registrar os aprendizados.
